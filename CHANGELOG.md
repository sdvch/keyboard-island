# Changelog

## 0.1.0 — 2026-10-20

Initial public source release of the 96-chapter game at https://github.com/shaom/keyboard-island.

- 16 worlds, 288 story phases, music playground and 36 room decorations.
- Optional local face-following diver character with explicit camera permission.
- Existing chapter IDs, item IDs and browser storage key preserved.
- English default README and Simplified Chinese README.
- MIT first-party license, Apache third-party notices and pinned asset hashes.
- Buildless local server, readable formatted source, automated checks and CI.
- Original demo voice recordings excluded pending established redistribution rights; all 147 transcripts and an optional pack importer included.

The existing hosted game remains unchanged by this source release.
