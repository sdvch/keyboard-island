# Security policy

This is a static, browser-local game. It has no account system, backend, application secrets, or database.

Do not include children's images, camera recordings, personal saves, credentials, or browser-profile exports in an issue. Describe the browser/version, expected behavior, and minimal reproduction using synthetic data.

For a vulnerability that could expose camera data or execute unintended code, contact the maintainer privately through the security channel displayed on the repository once it is published. GitHub private vulnerability reporting must be enabled by the repository owner before it is available. No private contact address is configured in this source-only release. Do not assume a public issue or ordinary pull request is a private channel.

When serving the game, use HTTPS, keep dependencies pinned, and preserve third-party notices. The application stops the camera on exit or page hiding, but browser permission controls and host policies still apply. There is no promise of support for every OS shortcut, extension, keyboard layout or browser release.
