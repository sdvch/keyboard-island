# 句子邮局

专门练习英文句首大写、单词空格和句末标点的独立打字游戏。新系列有单独的 ChatGPT Sites 站点；源码放在现有开源仓库的 `games/sentence-post-office/` 目录。原在线键盘小岛保持不变。

**[在线体验句子邮局](https://sentence-post-office-doudou.groovy-river-7567.chatgpt.site/post-office/)** · [系列选择页](https://sentence-post-office-doudou.groovy-river-7567.chatgpt.site/) · [GitHub 源码](https://github.com/shaom/keyboard-island/tree/main/games/sentence-post-office)

## 体验地址

启动：`node scripts/serve.mjs`（建议 Node.js 20 或以上）。

- 系列选择页：http://127.0.0.1:4186/
- 直接进入邮局：http://127.0.0.1:4186/post-office/

选择页中，键盘小岛连接到原有在线游戏；句子邮局使用独立课程、界面和进度。

## 本次玩法

四条路线，每条 8 封信，共 32 封：

- **Big A**：从句首开始，练习首字母大写。
- **Space Bridge**：从第一个单词后的空格开始，继续完成句子。
- **Stamp Shop**：字母已准备好，练习最后的句号、问号或感叹号。
- **Mail Run**：从空白信纸开始完整输入。

所有字符必须按顺序正确输入，大小写、空格、标点都算。输错的字符不会写入，光标停留，画面短暂抖动并柔和闪动，播放两声短音；正确重试后恢复。反馈用 `a → A`、单词之间的小桥、标点印章及大号按键图表示，不要求孩子阅读中文说明。不自动改正，不设倒计时，也不扣除邮票。

儿童界面使用插画、图标和少量简单英文；家长设置保留中文。没有系统机械朗读。背景音乐和各类动作音效在浏览器本机合成，可以关闭或调低。

每送达两封不同的信获得一枚邮票，共 16 枚；重玩不会重复增加奖励。家长可以查看进度、独立完成数量、曾出错的类别，并通过确认按钮清空邮局进度。“独立完成”要求该次没有输错、不点帮助、首次寄出成功；不表示孩子已经能脱离范例自行写作。

## 存档

只使用 `sentence-post-office-v1`，不读取或改写 `keyboard-island-v1`。当前信件和错误记录也会保存。关闭浏览器后，在同一浏览器、同一地址可以继续。换端口、换浏览器、使用无痕模式或清理站点数据可能无法恢复原存档。

没有账号、云同步、摄像头、录音或上传。无法写入浏览器存储时仍能游戏，但会提示本次不能保存。
